# 1 — Math & AI/ML Foundations

Core mathematics and machine learning theory that underpins modern AI systems.

## Topics Covered

- Linear algebra: vectors, matrices, eigendecomposition, SVD
- Calculus: gradients, chain rule, backpropagation by hand
- Probability & statistics: Bayes' theorem, distributions, MLE
- Information theory: entropy, KL divergence, cross-entropy loss
- Classical ML: linear/logistic regression, SVM, decision trees
- Neural network fundamentals: forward pass, loss, optimisers

## Notebooks

| Notebook | Topic |
|----------|-------|
| `01_linear_algebra.ipynb` | Matrix operations and vector spaces |
| `02_calculus_gradients.ipynb` | Derivatives and gradient descent |
| `03_probability.ipynb` | Probability distributions and Bayes |
| `04_classical_ml.ipynb` | Sklearn models from scratch |
